Todo experimento o desarrollo nuevo va en una carpeta NUEVA. Si hay que partir de código existente (p.ej. scripts de `D:\Script Etiquetas Venezuela`, inventario), primero copiarlo a la carpeta nueva y modificar la copia. Leer lo viejo está bien; escribir sobre él no.

**Why:** los scripts/sistemas actuales corren en producción (mote, inventario) y el usuario no quiere arriesgarlos.
**How to apply:** antes de crear/editar archivos para una idea nueva, crear carpeta dedicada (ej. `D:\Despacho_ML_Lab`) y trabajar ahí. Relacionado: [[project_mensajegrupo_flujo_mensual]].
