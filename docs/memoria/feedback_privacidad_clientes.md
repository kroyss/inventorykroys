Al redactar mensajes para clientes de El Comerciante Digital (Gerardo, Rubén, etc.), NUNCA decir "revisé tu cuenta" ni citar cifras o textos sacados de sus datos (preguntas, respuestas, ventas). El dueño lo considera invasivo y una ruptura de privacidad.

**Why:** 2026-10-11, propuse a Rubén un mensaje con "revisé tu cuenta… escribiste 195 veces…"; el dueño lo rechazó por privacidad.

**How to apply:** Si hace falta mirar datos de un cliente para diagnosticar, usarlos solo para orientar al dueño; el mensaje al cliente va en términos generales ("el sistema te mostrará…", "si respondes mucho lo mismo…"). Leer datos de clientes solo cuando el dueño lo pide. Relacionado: [[project_comerciantedigital_multiempresa]].
